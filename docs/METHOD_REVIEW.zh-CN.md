# 方法意见核查与本次调整

核查基础：当前源代码、ABC 官方 predictor/config 实现及公开 CRISPR 基准说明。以下区分代码事实、数学问题和待验证的生物学假设。

| 意见 | 判断 | 本次处理 |
|---|---|---|
| 近对角 NA 导致分母不完整 | 有道理。但原实现有匹配先验时会使用它，普通回退开关并不禁止近对角先验；同 bin 也不等于所有距离 <5 kb | 默认匹配先验优先，否则采用 cooler 输出的邻近最大值校正；均有来源记录。仍缺失时不输出完整主分数 |
| 缺失候选后分数被抬高 | 这是最需要修正的解释和输出问题；未知支持非负时，已知元件的子集份额只能作为完整份额的上界之一 | 主列默认完整分母才输出；条件列分开，并给基于支持范围的敏感性上下界 |
| 稀疏 Hi-C 的零使支持为零 | 零计数不能等同于没有生物学接触；加先验正则化有合理性，但需要同尺度参数和独立评估 | 增加可追踪的幂律伪计数，保留原始零；不对缺失活性造值，不重复叠加到 prior_only 或接触收缩上 |
| 没有 Hi-C 不易使用 | 原软件已有 fit-contact-prior 和显式先验模式，意见漏看了这部分；实际准备成本确实较高 | fit-prior 直接处理 cool/mcool；另提供主动选择、未验证标记的人类接触形状基线，不默认为畜禽参数 |
| 网格拆峰 | 一个峰可对应多个评分单元，但单位坐标唯一，不是复制同一个峰的支持数值；区域排名确实需要汇总 | 输出 region_scores，对一个 region 的单元去重求和；重叠 region 不作为新分母，说明与 ABC 峰顶窗口不等价 |
| B 与接触强度重复 | 代数展开正确，但并不等同于单纯 C 的幂：还包含元件特异的跨基因分母，注释敏感性是真实问题 | 无验证证据仍取零；基准增加 contact_power_2，要求独立比较和注释敏感性分析，不预称生物学竞争规律 |
| 多 TSS 太严格 | 同分辨率查询重复应复用；真正不同位置的缺失不能通过删 TSS、重归一化来掩盖 | 缺少重复查询时复用同元件/样本/bin 测量，保留原 TSS 权重；提供启动子实测信号制备权重命令 |
| 归一化全靠上游 | 新手操作问题成立；但从任意 bigWig 自动猜测 RPM 文库分母是不可靠的 | 原始片段计数支持 CPM/窗口长度归一化；已归一化信号保留协议，不默认跨动物分位数归一化 |
| 命令名称和配置复杂 | 大小写命令在不敏感文件系统上有冲突风险，手写合并和配对也不必要 | 仅安装小写 pace，增加 init、prepare-pairs、merge-tables；force 先备份已有 PACE 结果 |

新增的上下界是非负支持假设下的识别/敏感性范围，不是自动估计的置信区间。没有可信上界时区间可能很宽，不能为了显得精确而用未经验证的常数填满。

移除了根目录的临时开发指令、规划文件和 notes，维护说明统一到正式文档。Git 历史和已有来源记录仍保留。

论文应把核心问题写成“在实验活性已测、接触稀疏及注释不完整的条件下，能否获得更稳健的排序与明确的可评分范围”。[验证方案](ROBUSTNESS_VALIDATION.md)规定 K562 控制降采样、独立标签、覆盖率、接触指数对照和畜禽 eQTL 旁证。尚未实际运行这些生物学基准，不能据此声称优于 ABC 或预测文章接收概率。
