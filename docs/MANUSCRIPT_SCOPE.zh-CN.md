# 论文分析范围同步说明

## 当前方法范围

PACE 基于实测 ATAC、DNase 或 H3K27ac 信号构建调控活性，并结合来源明确的元件—启动子接触，对候选元件—基因关系计算相对支持。模型使用固定检测组合、去重后的物理 TSS 和预先确定的候选背景，保留真实零、缺失状态及实际评分覆盖。可选分配参数在合格独立功能数据支持下学习，否则取零。RNA、其他组蛋白标记、CTCF 和甲基化保留为注释或单独验证的分类器特征。

## 稿件需要同步修改的位置

| 位置 | 修改要求 |
|---|---|
| 摘要与研究目的 | 聚焦实测多组学支持的调控联系排序；删除仅凭基因组恢复组织活性或个体遗传效应的能力声明 |
| 方法与流程图 | 删除序列预测、实测/预测活性融合、个体序列重建和变异效应模块；给出当前总公式与实验输入 |
| 结果与补充材料 | 删除对应模块的性能结论与软件示例；若原有主结果用过这些模块，需要从实测数据重新计算 |
| 基准比较 | 使用相同候选背景和数据条件；明确标签来源、划分、负样本功效、覆盖率和实际比较对象 |
| 接触来源 | 区分实测接触与显式距离先验；使用先验的联系不描述成实验观察到的互作 |
| 讨论与局限 | 说明表观数据不齐、TSS 注释和接触覆盖限制；不声称软件消除了这些限制 |
| 代码与数据可用性 | 固定用于最终结果的提交号，提供对应配置、输入来源和可复现命令 |

## 方法段落建议

PACE 对预先定义的候选调控单元进行统一评分。首先，对通过质量控制并采用一致测量定义的实测活性信号，按技术重复、生物学重复和供体层级汇总；随后对预先固定的检测层组合计算几何平均活性。模型将同一基因不同物理转录起始位点的接触按固定权重汇总，并在适用独立功能数据支持下估计可选的跨基因分配指数。每条元件—基因关系的支持除以该基因实际可评分候选支持之和，得到相对调控支持分数。缺失证据、实际分母及覆盖范围均显式输出。附加组学的监督学习结果与主公式分列，并采用独立数据评价。

这段说明描述当前软件行为，不构成已完成实验的证明。稿件中的样本量、准确率、优于其他方法的结论和生物学验证必须对应真实分析结果；删除功能本身不能证明预测性能提高。
